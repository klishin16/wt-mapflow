# WT MapFlow

Интерактивная карта для War Thunder: наблюдение за боем, сохранение тактических
позиций и обозначение маршрутов подъезда.

## Возможности

- Карта боя с техникой, точками захвата и сгруппированными спавнами.
- Приближение, перемещение и плавное следование за игроком.
- Личные позиции с описанием, скриншотами, направлением стрельбы и маршрутом.
- Подсказки при приближении к позиции, редактирование и отмена удаления.
- Обзор всех маршрутов до первого появления игрока на карте; отключается в настройках.
- Импорт точек и маршрутов Ratline из JSON — файлом или вставкой текста.
- Направления от самолёта к вражеским танковым спавнам.
- Плавное приближение авиационной карты при подлёте к танковому бою и отдаление при отходе.
- Сворачиваемые настройки и деморежим без запуска игры.

## Быстрый запуск

Для запуска требуется Node.js **22.17 или новее**. После скачивания проекта
в его папке выполняются команды:

```bash
npm ci
npm run dev
```

Адрес приложения отображается в терминале, обычно `http://localhost:5173`.
War Thunder запускается на том же компьютере; карта появляется после входа в бой.
Сервис игры `http://127.0.0.1:8111` должен быть доступен.

Без игры доступен режим **«Настройки → Режим приложения → Демо без игры»**
или адрес приложения с параметром `?demo=1`.

## Как пользоваться

- **Колесо мыши / + / −** — масштаб; перетаскивание — свободный обзор.
- **«Следовать»** — возврат к игроку; **«Вся карта»** — обзор всей локации.
- **Правая кнопка мыши или долгое нажатие** — создание позиции.
  Нажатие на метку открывает её описание и маршрут.
- **«Настройки»** — размеры значков, видимость Ratline и ПВО, импорт и экспорт.
  ПВО аэродромов по умолчанию скрыто.
- **«Настройки → Танковая карта → Импорт JSON Ratline»** — вставка JSON
  или выбор файла, предпросмотр и импорт. Данные привязываются
  к текущей карте; совпадение названий с Ratline не требуется.
- Если карта не распознана, доступен ручной выбор в **«Настройки → Определение карты»**.

Позиции и настройки сохраняются в браузере. **«Экспорт»** предназначен для резервного
копирования и переноса личных позиций со скриншотами. При импорте Ratline требуется
проверка совпадения границ карт: обрезанные варианты могут требовать настройки координат.

## Админ-панель

Страница `/admin.html` или **«Настройки → Режим приложения → Админ-панель»**
содержит список всех карт из общего каталога проекта, поиск и фильтры. По названию
открывается карточка с вариантами режимов, размерами сетки и хешами распознавания.
Доступны добавление, переименование и удаление карт, просмотр и удаление хешей.
Запущенная игра не требуется.
